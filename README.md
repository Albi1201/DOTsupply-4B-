# Teori Singkat :
Perangkat lunak (software) adalah kumpulan program komputer yang dilengkapi dengan dokumentasi, seperti kebutuhan sistem, rancangan desain, dan panduan penggunaan. Tanpa adanya dokumentasi, sebuah program belum bisa disebut perangkat lunak. Perangkat lunak juga sering disebut sistem perangkat lunak, yaitu sekumpulan komponen yang saling berhubungan untuk mencapai tujuan tertentu.
Sistem perangkat lunak terdiri dari komponen-komponen yang saling terhubung untuk memenuhi kebutuhan pelanggan. Pelanggan adalah individu atau organisasi yang memesan atau membeli perangkat lunak dari pengembang, biasanya dengan mengeluarkan biaya secara sukarela. Sementara itu, pengguna (user) adalah orang yang menggunakan perangkat lunak untuk membantu dan mempermudah pekerjaannya.
