# DOTsupply
Sistem manajemen toko sembako berbasis websitee dengan framework css-bootstrap sebagai frontend, dan Framework code igniter PHP
Fitur
1. Login
2. multi user
3. Menu kasir
4. Id barang dengan terintegrasi alat scan barcode atau pun kiriman menggunakan file foto
5. Tambah data
6. Details data berisi Info supplier hingga produk expired
7. Import data laporan per bulan .excel
